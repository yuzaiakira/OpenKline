# Code of Conduct

We want OpenKline contributions to be respectful, constructive, and focused on
maintainable software. Participants must not harass, discriminate against, or
threaten others, publish private information, or disrupt project work through
bad-faith submissions.

Report conduct concerns privately to the project owner through the repository's
maintainer contact. Maintainers may remove comments, reject contributions, or
restrict participation when necessary to keep the project safe and productive.
