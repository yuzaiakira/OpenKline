# OpenKline proposed licensing materials

Status: **Policy proposal and legal-review materials only. They are not an
effective license grant, legal advice, package metadata, or publication
authorization.** Qualified legal counsel must review and the authorized
copyright holder must adopt any final text before a root `LICENSE`, `NOTICE`,
or package `license` field changes.

The current owner-confirmed policy is drafted in
[`openkline-source-available-license-proposal.md`](./openkline-source-available-license-proposal.md).
It is a custom source-available proposal, not an OSI-approved Open Source
license. The related documents are:

- [`licensing-policy-examples.md`](./licensing-policy-examples.md): practical
  permitted, prohibited, and escalation examples.
- [`license-compatibility-analysis.md`](./license-compatibility-analysis.md):
  non-binding compatibility analysis for consumer applications using
  OSI-approved licenses.
- [`ownership-and-approval-checklist.md`](./ownership-and-approval-checklist.md):
  owner and counsel review record.

`apache-2.0-proposal.md` and `LICENSE-APACHE-2.0.PROPOSED` are retained only
as superseded historical proposal material. They must not be renamed,
activated, or represented as the current OpenKline policy.
