# Superseded Apache-2.0 proposal record

Status: **Superseded as a policy proposal; not an effective license grant.**

This file previously described Apache License 2.0 as the preferred OpenKline
licensing candidate. The project owner has since confirmed a different policy:
a custom source-available proposal that permits use only by Consumer
Applications meeting the documented free, public-source, no-advertising,
no-paid-feature, no-subscription, and donation conditions.

The current policy draft is
[`openkline-source-available-license-proposal.md`](./openkline-source-available-license-proposal.md).
Its compatibility analysis, practical examples, and ownership/counsel checklist
are linked from [`README.md`](./README.md).

`LICENSE-APACHE-2.0.PROPOSED` remains in the repository only as unadopted
historical draft material. It must not be renamed to `LICENSE`, added to package
metadata, represented as the current policy, or used to authorize distribution.
The project currently has no effective root software license or npm `license`
field. Qualified legal counsel and the authorized copyright holder must approve
final text, ownership/provenance, third-party notices, and an adoption commit
before any effective license or publication action.
