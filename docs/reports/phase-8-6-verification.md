## Implemented capabilities

### Accessibility

- Public Canvas charts retain `role="img"` and keyboard focusability and now
  receive a dynamic, localized `aria-label` summarizing the visible time
  range, latest close, visible series, and pane count.
- Empty charts expose the explicit state `Financial price chart; no data
  loaded`.
- The summary is an orientation aid, not a complete data table and not a
  substitute for screen-reader or WCAG conformance review.
- Studio dialogs expose `aria-describedby`, close on Escape, and restore focus
  to the invoking watchlist control.
- Existing control names, status semantics, keyboard focus behavior, and
  touch-sized layouts remain covered by the React browser suite.

### Visual review

- Desktop dark theme, desktop light theme, and narrow-layout screenshots are
  generated by deterministic Playwright tests.
- Each candidate has an adjacent `*.image-difference.json` report containing
  byte counts, SHA-256, comparison status, and provenance notes.
- Baselines are never created or approved by the test. A supplied baseline is
  compared strictly and a mismatch fails the test.

### Evidence tooling

- The managed-browser runner records exact Playwright version, executable
  paths, launch policy, project list, result totals, and artifact hashes.
- The API inventory now excludes `private` and `protected` declaration members
  from public compatibility signatures. This avoids treating an internal
  accessibility helper as a breaking public API change.
- Distribution evidence was regenerated after the implementation change.

changed. The accessibility work updates Canvas metadata during the existing
render lifecycle; no measurable regression was identified by this run.
